- 香港優惠折扣網 – 18區商場生活導航 SPA 規格書
- 1 核心需求與呈現方式
	- 採用 **SPA（單頁應用）** 動態篩選模式，點擊分頁或標籤時不刷新頁面。
	- 使用 JavaScript 讀取 `malls.json` 並動態渲染商場與店家卡片。
- 2 數據結構規格 (malls.json)
	- **地區層級**：18區（如油尖旺、中西區、沙田等）。
	- **商場層級**：商場名稱、地址、商場 ID。
	- **店家層級**：
		- 店家名稱 (`store_name`)
		- 樓層位置 (`floor`)
		- 聯絡電話 (`phone`)
		- 優惠內容 (`deals`: 標題、開始日期 `start_date`、結束日期 `end_date`)
- 3 前端動態分類與日期過濾邏輯
	- [ ] **今日進行中的優惠店**：`start_date <= 今日` 且 `end_date >= 今日`
	- [ ] **3天內即將開始的優惠店**：`start_date` 介於 `今日 + 1天` 至 `今日 + 3天` 之間
	- [ ] **自動隱藏/刪除過期優惠**：`end_date < 今日` 之資料不予渲染
