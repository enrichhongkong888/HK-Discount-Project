- ### 2.2 前台主要頁面設計要點
- **Home 首頁**：大型輪播 Banner、快速類別與 18 區入口、今日熱推（Daily Special）、新增折扣列表。
- **18 區商場導航頁**：結合地圖與分區清單，展示商場基本檔案（地址、聯絡電話、網絡電話/客服、官方網站）及該商場的即時優惠。
- **主題樂園與指定專區頁**：獨立呈現迪士尼與海洋公園的門票折扣、全年證及季節性套票，並清楚標示所屬地區與效期。
- **優惠詳情頁**：大圖、品牌/商場 LOGO、詳細條件、有效期限倒數計時器、「複製折扣碼」或「直接跳轉」按鈕、雙軌效期提示。
- ## 3️⃣ 品牌頁與商場頁（Brand & Mall Page）結構
- **商場檔案頁（Malls Page）**：
	- **基本檔案**：商場名稱、所屬香港 18 區、詳細地址、聯絡電話、網絡電話 / 線上客服、官方網站網址 (`mall_url`)。
	- **商場優惠列表**：展示該商場內各商戶的最新優惠（支援分類與到期日篩選）。
- **品牌頁（Brand Page）**：
	- **品牌資訊**：LOGO、官方簡介、官方網站連結。
	- **品牌優惠列表**：按最新或人氣排序，可切換「折扣碼」或「滿減」等類型。
	- **品牌動態**：新品上架、活動公告。
- ## 4️⃣ 優惠種類（Discount Types）與生命週期分類
  
  | **類型定義** | **常見使用情境** | **前端顯示標籤** |
  | ---- | ---- | ---- |
  | **折扣碼 (Coupon Code)** | 網路購物、餐飲外送代碼輸入 | 折扣碼 |
  | **滿額減 (Spend-X Get-Y)** | 餐廳、百貨、電商滿額折抵 | 滿額減 |
  | **現金回饋 (Cashback)** | 完成購買後返現 | 回饋 |
  | **贈品 / 免運 (Free Gift / Shipping)** | 美妝、服飾贈送或免運 | 免運/贈品 |
  | **期間限定 (Limited Time)** | 節慶、季末清倉 | 限時特惠 |
  | **買一送一 (BOGO)** | 餐飲、飲料、零食 | 買一送一 |
  | **每日最新特惠 (Daily Special)** | 當日限定閃購，**嚴格限制 1 天後自動刪除** | 每日最新 (限時1天) |
- ## 5️⃣ 後台資料收集與管理規劃（Admin & Data Pipeline）
- ### 5.1 資料來源與爬蟲架構
- **設定檔驅動爬蟲**：採用 Python（Playwright / BeautifulSoup）結合 `sources.json` 設定檔，支援多來源動態擴充與防爬機制（每次請求強制加入 2-3 秒隨機延遲）。
- **爬取目標範圍**：
	- 香港 18 區商場檔案與商戶優惠。
	- 機票比較網與旅遊格價平台。
	- 自助餐優惠網（KKday / Klook / OpenRice 等）。
	- 香港主題樂園（香港迪士尼樂園、香港海洋公園官方優惠頁）。
- ### 5.2 雙軌資料生命週期與自動清理機制
- **軌道一（每日最新折扣）**：標記為 `is_daily_special: true` 的限時優惠，嚴格限制生命週期為 1 天，超過 1 天後系統執行時自動清除。
- **軌道二（18 區商場與分類資料）**：依據 `expiry_date`（有效期限）進行管理，在到期日前完整保留於對應的 18 區及專區中，超過到期日後自動刪除。

  ```
  -- 18 區商場檔案表格
  CREATE TABLE malls (
    id            SERIAL PRIMARY KEY,
    mall_name     VARCHAR(120) NOT NULL,
    district      VARCHAR(50) NOT NULL,       -- 香港 18 區（例如：油尖旺區、中西區）
    address       TEXT NOT NULL,
    phone         VARCHAR(50),
    network_phone VARCHAR(50),                -- 網絡電話 / 線上客服
    mall_url      TEXT,                       -- 商場官方網站
    created_at    TIMESTAMP DEFAULT now(),
    updated_at    TIMESTAMP DEFAULT now()
  );
  
  -- 品牌表格
  CREATE TABLE brands (
    id          SERIAL PRIMARY KEY,
    name        VARCHAR(120) NOT NULL,
    logo_url    TEXT,
    website     TEXT,
    description TEXT,
    created_at  TIMESTAMP DEFAULT now(),
    updated_at  TIMESTAMP DEFAULT now()
  );
  
  -- 優惠折扣表格（整合雙軌生命週期與 18 區/分類）
  CREATE TABLE discounts (
    id               SERIAL PRIMARY KEY,
    brand_id         INT REFERENCES brands(id) ON DELETE CASCADE,
    mall_id          INT REFERENCES malls(id) ON DELETE SET NULL, -- 關聯 18 區商場（若適用）
    category         VARCHAR(50) NOT NULL,      -- '商場優惠', '機票', '自助餐', '主題樂園'
    district         VARCHAR(50),               -- 香港 18 區分類或樂園專屬分區
    title            VARCHAR(255) NOT NULL,
    short_desc       TEXT,
    detail_url       TEXT NOT NULL,
    discount_code    VARCHAR(50),               -- nullable
    amount_off       NUMERIC(10,2),
    percent_off      NUMERIC(5,2),
    min_spend        NUMERIC(10,2),
    gift_desc        TEXT,
    is_daily_special BOOLEAN DEFAULT FALSE,     -- 軌道一：是否為每日最新折扣 (限時 1 天)
    created_date     DATE NOT NULL DEFAULT CURRENT_DATE, -- 用於計算 1 天時效
    expiry_date      DATE NOT NULL,             -- 軌道二：到期日
    is_active        BOOLEAN DEFAULT TRUE,
    source           VARCHAR(50) NOT NULL,      -- SCRAPING / API / USER_SUBMIT
    audit_status     VARCHAR(20) DEFAULT 'PENDING'
  );
  ```

- ### 5.4 後台管理與合規機制
- **自動清理排程**：每日定時執行清理腳本，自動刪除 `is_daily_special = true` 且建立超過 1 天的資料，以及超過 `expiry_date` 的一般分類/分區資料。
- **合規與隱私**：遵守香港《個人資料（私隱）條例》（PDPO），爬蟲前檢驗目標網站之 robots.txt 與服務條款。
- ## 6️⃣ 推薦技術棧
- **前端**：React + Next.js + TypeScript + Tailwind CSS
- **後端**：NestJS (Node.js) + PostgreSQL + Prisma ORM
- **爬蟲與自動化**：Python (Playwright / BeautifulSoup) + `sources.json` 設定檔管理
- **排程與快取**：Redis + Cron Job（執行雙軌資料自動清理與爬蟲任務）
