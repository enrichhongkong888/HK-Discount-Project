	  ## 4️⃣ 優惠種類（Discount Types）分類
	  
	  | 類型 | 定義 | 常見使用情境 | 前端顯示標籤 |
	  |------|------|--------------|------------|
	  | **折扣碼 (Coupon Code)** | 用戶在結帳時輸入的代碼 | 網路購物、餐飲外送 | `折扣碼`、`代碼：XYZ123` |
	  | **滿額減 (Spend‑X Get‑Y)** | 滿一定金額減免金額或折扣 | 餐廳、百貨、電商 | `滿HK$500減HK$50` |
	  | **現金回饋 (Cashback)** | 完成購買後返現至信用卡/支付寶 | 旅遊、線上購物 | `回饋20%` |
	  | **贈品 / 免運 (Free Gift / Free Shipping)** | 付費即贈送商品或免運 | 美妝、衣服 | `免運費`、`贈送口紅` |
	  | **期間限定 (Limited Time)** | 僅在特定日期或時間內有效 | 節慶、季末清倉 | `限時 12/12‑12/31` |
	  | **買一送一 (BOGO)** | 購買一件贈送同價或指定商品 | 餐飲、飲料、零食 | `買一送一` |
	  | **套裝／組合優惠 (Bundle)** | 多件商品一起折扣 | 電子、家電 | `組合折扣 30%` |
	  | **會員專屬 (Member‑Only)** | 只開放給平台會員 | 任何類別 | `會員專享` |
	  | **抽獎／粉絲專屬 (Sweepstakes)** | 完成指定任務抽獎 | 社群活動 | `抽獎` |
	  
	  > **前端標籤**：建議使用彩色小徽章（如藍、紅、綠）提升辨識度。點擊徽章可自動加入篩選條件。

	  ## 5️⃣ 後台資料收集與管理規劃（Admin / Data Pipeline）
	  
	  ### 5️⃣1 資料來源
	  
	  | 來源 | 方法 | 說明 |
	  |------|------|------|
	  | **品牌合作夥伴 API** | 定時抓取（OAuth2） | 直接取得品牌官方折扣資料，保證正確性 |
	  | **爬蟲（Web Scraping）** | Python/Node.js + Selenium / Playwright | 針對公開的折扣網站、社群貼文、Google Sheet 等自動抓取 |
	  | **用戶自報** | 前端「提交優惠」表單 + 檢核機制 | 鼓勵社群貢獻，降低資訊盲點 |
	  | **第三方聯盟平台** | CSV 匯入、Webhook | 如 ShopBack、Klook 異業合作 |
	  | **活動/官網 RSS** | RSS 解析器 | 抓取品牌新聞、促銷活動 |
	  | **政府或公共資料** | 開放資料平台（如香港旅遊發展局） | 旅遊優惠、交通票券等合法資訊 |
	  
	  ### ⑤2 資料清洗與驗證
	  
	  1. **結構化驗證**  
	     - 必填欄位：`title、brand_id、discount_type、valid_from、valid_to、detail_url`  
	     - 正則表達式驗證 **折扣碼** 格式、金額範圍、URL 合法性  
	  
	  2. **重複檢測**  
	     - 以 `title + brand_id + valid_from` 為唯一鍵，避免同一優惠重複上傳  
	  
	  3. **真偽驗證**  
	     - 自動測試 URL 是否 200 OK、是否含有折扣碼或促銷文字  
	     - 定期（每日/每週）檢查過期或失效的優惠  
	  
	  4. **內容審核**  
	     - 機器學習模型（文本分類）偵測違禁詞、非法促銷（如抽血抽菸等）  
	     - 人工審核隊列：高風險/新品牌需手動確認  
	  
	  ### ⑤3 資料庫設計（以 PostgreSQL 為例）
	  
	  ```sql
	  -- 主要表格
	  CREATE TABLE brands (
	      id          SERIAL PRIMARY KEY,
	      name        VARCHAR(120) NOT NULL,
	      logo_url    TEXT,
	      website     TEXT,
	      description TEXT,
	      created_at  TIMESTAMP DEFAULT now(),
	      updated_at  TIMESTAMP DEFAULT now()
	  );
	  
	  CREATE TABLE discount_types (
	      id   SMALLSERIAL PRIMARY KEY,
	      code VARCHAR(30) UNIQUE NOT NULL,   -- e.g. COUPON, CASHBACK, BOGO
	      label VARCHAR(30) NOT NULL
	  );
	  
	  CREATE TABLE discounts (
	      id               SERIAL PRIMARY KEY,
	      brand_id         INT REFERENCES brands(id) ON DELETE CASCADE,
	      type_id          INT REFERENCES discount_types(id),
	      title            VARCHAR(255) NOT NULL,
	      short_desc       TEXT,
	      detail_url       TEXT NOT NULL,
	      discount_code    VARCHAR(50),               -- nullable
	      amount_off       NUMERIC(10,2),             -- cash amount
	      percent_off      NUMERIC(5,2),              -- 0~100
	      min_spend        NUMERIC(10,2),             -- 滿額
	      gift_desc        TEXT,                      -- 免運 / 贈品說明
	      valid_from       DATE NOT NULL,
	      valid_to         DATE NOT NULL,
	      is_active        BOOLEAN DEFAULT TRUE,
	      created_at       TIMESTAMP DEFAULT now(),
	      updated_at       TIMESTAMP DEFAULT now(),
	      source           VARCHAR(50) NOT NULL,      -- API / SCRAPING / USER_SUBMIT
	      source_ref_id    VARCHAR(100),              -- 原始平台唯一 ID
	      audit_status     VARCHAR(20) DEFAULT 'PENDING'   -- PENDING / APPROVED / REJECTED
	  );
	  
	  CREATE TABLE discount_tags (
	      id   SERIAL PRIMARY KEY,
	      name VARCHAR(30) UNIQUE NOT NULL
	  );
	  
	  CREATE TABLE discount_tag_map (
	      discount_id INT REFERENCES discounts(id) ON DELETE CASCADE,
	      tag_id      INT REFERENCES discount_tags(id) ON DELETE CASCADE,
	      PRIMARY KEY (discount_id, tag_id)
	  );
	  
	  -- 用戶相關
	  CREATE TABLE users (
	      id            SERIAL PRIMARY KEY,
	      email         VARCHAR(120) UNIQUE NOT NULL,
	      password_hash TEXT NOT NULL,
	      name          VARCHAR(80),
	      is_admin      BOOLEAN DEFAULT FALSE,
	      created_at    TIMESTAMP DEFAULT now()
	  );
	  
	  CREATE TABLE user_favorites (
	      user_id     INT REFERENCES users(id) ON DELETE CASCADE,
	      discount_id INT REFERENCES discounts(id) ON DELETE CASCADE,
	      created_at  TIMESTAMP DEFAULT now(),
	      PRIMARY KEY (user_id, discount_id)
	  );
	  ```

	  1. **結構化資料（Schema.org）**  
	     - `Product`, `Offer`, `Brand`、`AggregateRating` 標記

	     - `description` 限制在 150 字內，含關鍵字「香港折扣、優惠碼」  
	  3. **動態 Sitemap**  
	     - 每 6 小時自動更新 `sitemap.xml`，包括所有有效優惠與品牌頁  
	  4. **內部連結**  
	     - 相關優惠間互相鏈接、品牌頁底部列出「相似品牌」推薦  
	  5. **UGC（用戶生成內容）**  
	     - 允許使用者留言、評分，提升長尾關鍵字

	  ## 9️⃣ 小結
	  
	  - **前台** 以「類別 → 品牌 → 優惠類型」三條主線串聯，提供快速篩選與深度品牌資訊。  
	  - **品牌頁** 為品牌曝光與合作夥伴自主管理的入口，具備資訊、優惠、互動三大區塊。  
	  - **優惠類型** 明確分類（折扣碼、滿額減、回饋…），前端以顏色徽章呈現，提升使用者搜尋效率。
